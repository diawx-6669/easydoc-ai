# EasyDoc AI 📝

**EasyDoc AI** — это интеллектуальный веб-сервис для автоматизированной генерации юридических документов в формате Word (.docx). Приложение создано для оптимизации рутинных задач малого бизнеса.

---

## 🚀 Основные возможности

* **Генерация документов:** Создание трудовых договоров, договоров аренды, купли-продажи имущества, услуг и транспортных средств.
* **Автоматизация:** Заполнение данных сторон и условий за секунды.
* **Мультиязычность:** Поддержка трех языков: **Русский**, **English**, **Қазақша**.
* **Предпросмотр:** Возможность просмотреть ключевые детали документа перед скачиванием.
* **Удобство:** Готовый файл .docx с профессиональным форматированием (Times New Roman, 12pt).

---

## 🛠 Стек технологий

* **Frontend/Backend:** Python, Streamlit.
* **Библиотеки:** `python-docx` (генерация Word), `pytz` (работа с часовыми поясами).
* **Среда разработки:** Конфигурация Dev Containers для быстрой развертки в GitHub Codespaces.

---

## ⚙️ Запуск проекта

### Через Dev Container (Рекомендуется)
Проект полностью настроен для использования в VS Code или GitHub Codespaces:
1. Откройте репозиторий в **Codespaces** или локально через **Dev Containers**.
2. Контейнер автоматически установит зависимости из `requirements.txt`.
3. Приложение `app.py` запустится автоматически на порту `8501`.
